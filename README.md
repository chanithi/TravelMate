# TravelMate

**TravelMate** is a mobile application built with **Android Studio** using **Java**, designed to help travelers find suitable **drivers**, **guides**, and **hotels** with ease. The app supports district-based filtering and provides a user-friendly interface for browsing and booking services.

---

## Features

-  **User Authentication**
  - Separate login/registration for:
    - Customers
    - Drivers
    - Guides
    - Hotels
  - Firebase Authentication used for secure login.

-  **Search and Filter**
  - Users can search by three categories:
    - Drivers
    - Guides
    - Hotels
  - Filter results by district.

-  **Detailed Listings**
  - Selecting a listing opens a detail page with:
    - Name
    - Contact Number
    - Email
    - District
    - Other relevant info

-  **Profile Management**
  - Drivers, Guides, and Hotels can **edit/update** their profiles.
  - Admin can **delete** any listing or user.

-  **Request/Booking Form**
  - Customers can send requests to providers with service dates and contact details.
  - Providers receive the request and can **accept or reject** it.

---

## Tech Stack

- **Platform:** Android
- **Language:** Java
- **IDE:** Android Studio
- **Database:** Firebase Firestore
- **Authentication:** Firebase Authentication
- **Storage:** Firebase Storage (for image uploads)
